# Four-loop UI and content improvement

Objective: improve the actual servicing briefs and their governing UI/content principles through four complete review, implementation and verification loops. The audience is a mortgage-servicing profitability and financial-oversight leader. The product remains a lean email brief with original evidence, not a dashboard or a general bank-earnings digest.

Each loop re-reads the original objective, the current UI/content standard, source-insight policy, the actual reader output and prior findings. It identifies contradictions, expands only principles needed to prevent observed failures, implements the smallest effective fixes, and verifies actual output. Root reviews Luna Max work. A separate Astra Max gatekeeper defines a rubric grounded in the original objective, inspects artifacts and evidence, scores the result out of 10, and must award strictly above 9.0 before the next loop begins. Rejected loops are revised within that loop. A score is an editorial judgment, not proof of flawless output.

Planned emphasis, without excluding either UI or content from any loop:

1. Reader purpose and truthful selection: resolve weak content, support concise coverage notes, align prominence with meaning, preserve source evidence.
2. Reading and navigation: inspect the entire desktop/mobile/email experience, improve the top-to-bottom flow, typography and source access; challenge all remaining copy again.
3. Interpretation: challenge units, dates, populations, causation, rates, outlook, visual scales and evidence links; review whether clarity controls introduce clutter.
4. Regression and handoff: repeat the whole review against the final artifacts and principles, test controls at release boundaries, simplify unnecessary machinery and verify all four gate decisions.

Working revisions live in `output/brief-improvement`. Loop records live under `output/brief-improvement/loop-N`. Sent PDFs, prior audited HTML and immutable financial evidence are preserved. No new email send, scheduling activation or public deployment is authorized by this review goal.

User steering during loop 1 adds company branding to the core UI principles: official logo and verified company colors for every company brief, recognizable publisher identity, consistent reading structure, accessible image fallback, and no confusion between brand colors and financial signals. Incorporate this in implementation and each Astra gate rubric.

Loop state is recorded in `output/brief-improvement/loops.json`. An existing aesthetic approval or prior P0 audit cannot substitute for a gate decision in this four-loop goal.
